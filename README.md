Setting up a PHP project using XAMPP is a straightforward process. Here's a step-by-step guide:

Step 1: Download and Install XAMPP

1. Go to the Apache Friends website (http://www.apachefriends.org/) and download the XAMPP installer for your operating system (Windows, macOS, or Linux).
2. Run the installer and follow the prompts to install XAMPP.

Step 2: Configure XAMPP

1. Open the XAMPP Control Panel (usually found in the Start menu or Applications folder).
2. Start the Apache and MySQL services by clicking the "Start" button next to each service.

Step 3: Create a new PHP project

1. Create a new folder for your project in the XAMPP htdocs directory (usually located at C:\xampp\htdocs on Windows or /Applications/XAMPP/xamppfiles/htdocs on macOS).
2. Create a new PHP file (e.g., index.php) in your project folder.

Step 4: Configure the project

1. Open your PHP file in a text editor or IDE (e.g., Visual Studio Code, Sublime Text).
2. Write your PHP code in the file.

Step 5: Access your project

1. Open a web browser and navigate to http://localhost/your-project-folder-name (replace "your-project-folder-name" with the actual name of your project folder).
2. You should see your PHP project running.
3. Create a database 
4. Navigate to include folder and locate function.php
6. create the database credentials such dbname,host,username and password
7. Run the code and login 
8. Please login with default admin information at the index.php file 

Additional tips:

- Make sure Apache and MySQL services are running in the XAMPP Control Panel.
- You can access phpMyAdmin (a database management tool) by navigating to http://localhost/phpmyadmin in your web browser.
- You can configure XAMPP settings (e.g., PHP version, document root) in the httpd.conf file (usually located at C:\xampp\apache\conf on Windows or /Applications/XAMPP/xamppfiles/etc/httpd.conf on macOS).

That's it! You should now have a PHP project set up using XAMPP.
